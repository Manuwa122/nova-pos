Questions answered

Everything you need to know.

Can NovaPOS support large companies?

The current product is a browser-local demonstration, suitable for evaluating the workflow. Large companies could use a future customized deployment, but secure multi-user access, cloud databases, centralized branches, auditing and enterprise support must be implemented first.

Do I need to install any software?

The current demo runs in a supported modern web browser. Camera scanning depends on browser permission, hardware capabilities and internet access to load its compatibility library.

Will data sync between multiple computers?

Not yet. The demo saves data to the current browser's local storage. Different computers do not share that data automatically.

Does NovaPOS process real card payments?

Not currently. Cash and external payment records can be entered manually, but payment gateway processing and verified settlements require additional integration.

Is NovaPOS available in Sinhala and English?

The website supports Sinhala and English presentation, and the application includes partial bilingual interface support.
